Guide Étape 2 : Type de Tarification

À propos de cette étape :

Choisissez votre mode de facturation. Ce choix détermine comment les frais du bloc opératoire seront calculés.

Tarification À la durée :
  • Prix de base du bloc opératoire avec une durée minimale incluse
  • Supplément appliqué pour chaque tranche de 30 minutes supplémentaires
  • Calcul automatique basé sur la durée réelle de l’intervention
Tarification Forfaitaire :
  • Forfait à tarif fixe avec durée et consommation définies
  • Inclut généralement : bloc opératoire, consommables, actes et nuitées prévues
  • Tout dépassement de la durée ou de la consommation incluse entraîne des frais supplémentaires
Conseil : Le forfait est recommandé pour les interventions standards à durée maîtrisée. La tarification à la durée est préférable pour les cas complexes ou à durée imprévisible.

Guide Étape 2 & 3 : Tarification & Sélection

Les 2 modes de facturation :

À la durée :

  • Prix de base du bloc opératoire
  • Supplément par tranche de 30 min supplémentaires
  • Flexibilité maximale
  • Idéal quand la durée est incertaine

Forfaitaire :

  • Tarif fixe tout compris
  • Inclut bloc + nuitées + certains produits/actes
  • Économie garantie
  • Idéal pour interventions planifiées
Sélection du bloc :
  • Durée base : Durée minimale incluse dans le tarif
  • Prix supplémentaires : Coût pour chaque tranche de 30 min au-delà
  • Chaque bloc a ses propres tarifs et conditions
  • La sélection du mode (durée/forfait) affecte le choix disponible
Conseil : Comparez bien les inclusions et le rapport qualité-prix avant de confirmer votre choix.

Guide Étape 4 : Produits & Actes

À propos de cette étape :

Gérez tous les éléments facturables : produits consommés, actes médicaux, et prestations d'anesthésie.

Produits :
  • Inclus : Produits fournis avec le bloc/forfait - affichés en lecture seule
  • Supplémentaires : Produits additionnels à ajouter
  • Seuls les supplémentaires augmentent le coût
  • Les quantités incluses sont déduites automatiquement
Actes médicaux :
  • Inclus : Actes fournis avec le forfait
  • Supplémentaires : Actes additionnels nécessaires
  • Chaque acte a son propre tarif
  • Facturation des quantités supplémentaires uniquement
Anesthésie :
  • Sélectionnez le type d'acte d'anesthésie
  • Affectez 2 intervenants : 1 réanimateur + 1 technicien
  • Chaque intervenant a un tarif spécifique
  • Total anesthésie = somme des 2 tarifs
  • Tous les 3 champs doivent être remplis
Automatique : Les totaux sont recalculés en temps réel à chaque modification.

Guide Étape 5 : Hospitalisation & Nuitées

À propos de cette étape :

Enregistrez toutes les nuitées en chambre pour le patient. Les tarifs varient selon le type de chambre et les nuits pré-opératoires.

Les types de nuitées :
  • Standard : Chambre standard incluse dans forfaits
  • Confort/VIP : Chambre supérieure (supplément appliqué)
  • Pré-opération : 1 seule nuit gratuite autorisée
  • Pré-op en chambre non-standard = facturation de la différence
Règles importantes :
  • Une hospitalisation = un séjour continu en même chambre
  • Pour un changement de chambre = nouvelle hospitalisation
  • Date de sortie > date d'entrée (système auto-valide)
  • Nuits forfaitaires incluses calculées automatiquement
  • Les nuits excédentaires sont facturées au tarif du jour
Exemple :

Forfait 500 DA avec 2 nuits incluses + patient avec 5 nuits = 3 nuits facturées au tarif chambre

⚠️ Nuit pré-op : Une seule gratuite par dossier, en chambre standard uniquement.

Guide Étape 6 : Explorations & Consommations

À propos de cette étape :

Enregistrez tous les examens complémentaires et consommations annexes liés au séjour et à l'intervention.

Types d'explorations :
  • Radiologie : Radiographies, IRM, scanner, échographie
  • Laboratoire : Analyses sanguines, biochimie, sérologie
  • Électrodiagnostic : ECG, EEG, EMG
  • Endoscopie : Endoscopies digestives, bronchiques, etc.
  • Autres : Consommations spéciales, fournitures annexes
Champs à remplir :
  • Type * : Obligatoire - catégorie de l'examen
  • Prix * : Obligatoire - coût de l'examen
  • Nom : Optionnel - description précise (ex: "IRM lombaire")
  • Date : Optionnel - date de réalisation
  • Observations : Optionnel - notes ou résultats importants
Bonnes pratiques :
  • Incluez les examens pré-opératoires (dosage, ECG, etc.)
  • Incluez les examens post-opératoires si facturés
  • Un examen = une ligne (même date, même type)
  • Les tarifs sont additionnés automatiquement au total
Conseil : Remplissez les observations pour tracer les résultats d'examens importants ou les achats spéciaux.
